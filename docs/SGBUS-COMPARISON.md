# 港巴通与 SG Bus 当前差异复核

日期：2026-10-20（Asia/Taipei）。本表替代“最初 25 项差异仍全部存在”的读法；[2026-10-19 历史差异快照](SGBUS-COMPARISON-HISTORICAL.md)保留供前后追溯。港巴通保留已锁定的 Accessible Calm Minimal、10 号 Logo、香港数据和移动优先范围，不把品牌选择当作缺陷。

**结论：仍有差异，但核心查车、收藏及显示偏好的差距已经缩小。最大的剩余区别在于实时车辆数据、交通网络范围、时间表适用范围、后台提醒、信息架构与发行验收。** 页面数量不能换算为“与 SG Bus 相似度”。

## 依据与状态

- SG Bus：本次重新阅读[官网](https://www.sgbus.app/)、[使用指南](https://www.sgbus.app/user-guide)、[FAQ](https://www.sgbus.app/faqs)及[隐私政策](https://www.sgbus.app/privacy-policy)。属于第一方公开功能声明，未安装和操作其原生 App。
- 港巴通：实际四客户端源码、真实后端与目录、最近正式 H5 验收；[本次地图与规划深化](MAP-PLANNER.md)的构建和网站发布状态以其独立证据为准。本次新增内容已在正式 H5 通过 22 组地图/规划、18 组既有能力和 28 组回归；官方 IDE/真机仍未验。
- 后端本次真实目录为 1,611 个路线方向/服务记录、6,775 个站点；不能称作 1,611 个独立路线号。仍仅覆盖 KMB/LWB。
- 小程序官方 IDE、Android/小程序真机、平台上传、应用商店发行分别验收，不由 Web 截图或 dist/APK 编译替代。

## 已补齐，不能继续列为“没有”的项目

| 能力 | 港巴通现状 | 仍需保持的语义 |
| --- | --- | --- |
| 线路与站点 ETA | 已接入真实站点/整线到站，按方向、服务类型及重复站序隔离；少于一分钟显示即将 | 过期、接口失败、暂无预计不同于停运 |
| 两班/三班与网格/列表 | 已有本机偏好，实际到站及收藏等复用 | 与 SG Bus 的设置入口位置不同 |
| 街道底图及完整线路 | 已有真实底图、全量站点、核对的官方道路几何、署名、缩放与点站；本次继续完善独立区域发现和选点 | 固定车站与官方路线不等于实时车辆地图 |
| 收藏直接查到站 | 已可展开 ETA、选择精确服务、置顶、命名、排序和管理 | 保留当前本机上限、请求合并及失效反馈 |
| 最近十站及距离 | 已有独立最近十站；用户主动定位后按本次位置计算距离 | 不保存精确定位，不提供跨设备同步 |
| 道路统一检索 | 已有核对的官方道路/站址、繁简与英文简称归一化、道路详情及线路道路关系 | 未匹配道路、普通 POI/完整地址仍不是完备地名服务 |
| 深色/系统主题、三档字号 | 已有浅色/深色/系统与小中大字号；保留繁简英 | 不能再写“只有固定浅色和两档字号” |
| 官方运营参考 | 已接入总站时刻、香港运行日与跨午夜解释 | 总站发车时刻不能移作每个中途站的首末班 |

## 当前仍有的功能及产品差异

| 板块 | SG Bus 公开能力 | 港巴通现状 | 差异性质与实际影响 |
| --- | --- | --- | --- |
| 主导航/打开后的第一任务 | 三个主 Tab 为 Nearby、Bookmarks、MRT/LRT；各 Tab 顶部搜索及校园入口 | 首页、路线、收藏、设置四入口；附近、完整地图、规划等从任务入口进入 | **信息架构取舍。** 打开后首先读到的内容与到附近/收藏的路径不同，尚非同一结构 |
| 首屏和内容密度 | 以附近发现及收藏查车组织主要任务 | 品牌首页、搜索、工具、当前站到站及常用出行；大留白与大字优先 | **视觉/交互差异。** 已有网格/列表不代表首屏布局、菜单位置和操作节奏逐像素一致 |
| 实时车辆地图 | 公开说明位置来自 LTA，可点车辆、跟踪屏外车辆，在路线及附近显示移动巴士 | 只有官方固定站、路线几何与实时 ETA，未取得可核实车辆 GPS/身份 | **数据缺口。** 不能看到某辆实车在两站之间；不得用 ETA 插值伪造追踪 |
| 车型/拥挤度 | 到站卡含当班车型和载客程度 | 没有可信车辆级车型、座位/站位或拥挤度数据 | **数据缺口。** 暂无法提供选空车、判断实车车型的同等信息 |
| 全交通网络 | 新加坡公共巴士、铁路资料及 NUS/NTU 接驳整合 | 当前 KMB/LWB；未覆盖全部香港营办商、港铁、轻铁或校园接驳 | **地域和网络范围不同。** 香港对应网络需要各自正式数据，不能把当前名称理解成全港全交通覆盖 |
| 铁路信息 | 公开列有铁路线路、站点出口/设施及运行异常；FAQ 明确没有实时列车到站源 | 没有相应香港铁路模块 | **范围缺口。** 对标项是铁路信息与服务状态，不能误写为 SG Bus 已提供实时列车到站 |
| 运营日/首末班的适用点 | 指南公开展示到站卡的运行时间线、无车服务解释及道路运营索引 | 已有九巴官方**起点总站**时刻与运行日；没有完整逐中途站首末班表 | **部分达到。** 能查总站运营参考，但不能等同于“此中途站的末班仍赶得上” |
| 到站提醒 | 隐私政策声明告警服务器接收安装 ID、设备推送令牌与选定服务 | 本机阈值提醒，仅前台取得新鲜 ETA 时检查；没有关闭后后台推送 | **交付方式不同。** 不建账号仍可技术上做推送，但会新增设备状态；当前本机资料规则未引入它 |
| 语言/大屏 | 官网称 23 种语言，并有平板/折叠屏布局 | 繁中、简中、英文；手机优先，主容器宽度受限，没有专用平板架构 | **定位差异。** 三语和移动范围符合当前确认要求；手机横屏不等于专用平板验收 |
| 定位计算与第三方 | 隐私政策称附近距离在设备计算；系统地址查询会用 Apple/Google，地图取相应区域瓦片 | 本次主动查询的位置/地图范围会传给自有 API；精确点只保留本次内存，坐标查询不写本机缓存；自有服务/相关 Nginx 日志不保存坐标 URL | **技术流程不同。** 不能将本产品写成“精确定位绝不离开设备”；地图/边缘服务仍接收请求网络及区域信息，第三方日志不在本次控制范围 |
| 发版与成熟度 | 第一方资料有 Android/iOS 原生产品及相关平台功能 | 三种 Taro 小程序、正式 H5 与 Android Debug APK；无本次 iOS 包；官方 IDE/真机/平台上架尚未完成验收 | **发行阶段不同。** 已编译/网页可访问不等于原生发行成熟度相同 |
| 广告/内购/统计 | FAQ/隐私政策公开广告、移除广告内购与 Firebase 相关流程 | 当前未接入相应商业化 SDK/流程 | **产品取舍。** 不是补齐查车能力的必要条件；双方都无乘客账号，不能将“免账号”当成相对弱项 |

SG Bus 表述均为本次读到的公开产品承诺，不据此保证所有历史商店版本相同。上表不使用未经测量的相似度、性能或易用性分数。

## 港巴通采用不同实现的工具

| 能力 | 本产品做法 | 比较的边界 |
| --- | --- | --- |
| 车费 | 应用内核对具体上下车站序的运输署成人普通单程价；未知、条件价、过期资料有独立状态 | SG Bus FAQ 的已确认入口是官方计算器外链；不能据此声称其原生内部绝无其他实现。当前香港报价不含所有票种与优惠 |
| 行程规划/核查 | 本次扩展至地图点接驳、最多两次转乘、步行上限、三方案比较与逐段出发核查；以专项完成证据为准 | 在已阅 SG Bus 公开资料中未确认同等候选算法与比较规则；本产品也不承诺实时最快、最低票价、真实步行导航或能赶上后续班次 |
| 常用站对/候车看板 | 本机保存常用有向站对与精确服务/站序看板，每次重新查真实数据 | 本产品的独立复用工具；不是用工具数量证明参考体验已完全复制 |
| 道路交通 | TDAS 查询独立的道路行驶时间、距离和过海备选 | 香港本地扩展；不换算成巴士 ETA、巴士乘车时间或车辆位置 |
| 管理后台 | 自有同步、配置、内容、来源和收费维护 | 参考产品后台未公开；不能把“没有公开”当作“没有后台” |

## 后续优化应如何排序

1. 继续以“打开后查看常用几班车”的步骤与一屏可读信息核查首页和收藏，避免入口增长掩盖查车任务；保留已确认导航与风格。
2. 将独立地图、区域列表、完整行程及逐段核查的真实页面证据闭环，处理无定位、无结果、来源错误与返回恢复。
3. 如要进一步达到实时车辆/拥挤度/铁路体验，先明确香港对应数据的可用性与字段；如要后台推送，先明确设备状态与当前本机资料规则的关系。
4. 对已经编译的三个小程序与 Android 分别执行官方 IDE、真机及平台发行验收，再讨论原生完成度，不能拿 H5 通过替代。
